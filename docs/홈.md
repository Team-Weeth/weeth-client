## 폴더 지도

| 폴더      | 용도                                              |
| ------- | ----------------------------------------------- |
| `기획/`   | 무엇을 만들까. 한줄 요약, 기능 명세, 담당                       |
| `아키텍처/` | 어떻게 만들까. 도메인 용어집, ADR(결정 기록)                    |
| `회의록/`  | 언제 누가 무엇을 결정했나                                  |
| `로그/`   | 각자의 Claude Code 세션 기록 (`세션로그-이름-YYYY-MM-DD.md`) |
| `트러블슈팅/` | 겪은 에러와 해결법                                       |
| `온보딩/`  | 신규 합류자가 읽을 문서                                   |
| `레퍼런스/` | 외부 자료, 학습 노트                                    |
| `템플릿/`  | 회의록·ADR·세션로그 양식                                 |

## 작성 규칙

- **결정은 ADR에**, 토론은 회의록에, 작업은 세션로그에.
- 다른 문서를 참조할 때 항상 `[[위키링크]]` 사용 — 백링크가 자동으로 쌓인다.
- 사람 이름은 `@민수`처럼 태그 형태로 일관되게.
- Claude Desktop과의 긴 대화를 통째로 붙여넣지 않는다. **결정 사항과 이유**만 정리.

- 작업 시작 시 세션로그 시작: `로그/세션로그-이름-YYYY-MM-DD.md` ([[템플릿/세션로그-템플릿]] 복사)
