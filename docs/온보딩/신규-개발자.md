# 신규 개발자 온보딩

Weeth 팀에 합류한 걸 환영합니다. 아래 순서대로 읽으면 됩니다.

## 1일차: 읽기

1. [[../홈]] — 전체 지도
2. [[../기획/프로젝트-개요]] — 우리가 만드는 것
3. [[../아키텍처/도메인-용어집]] — 우리가 쓰는 단어
4. [[../아키텍처/결정-기록/README|ADR 목록]] — 우리가 정한 규칙과 이유
5. 루트의 `CLAUDE.md`와 `.claude/rules/` — 코드 규칙

## 1일차: 환경 세팅

- Node.js LTS + **pnpm** 설치 (npm/yarn 금지)
- `pnpm install`
- `pnpm dev`로 동작 확인
- 옵시디언 설치 → "다른 볼트 열기"로 `weeth-client/docs/` 폴더 열기

## 2일차부터: 작업 흐름

- 아침: 다른 팀원 [[../로그/README|세션 로그]] 훑기
- 작업 시작: 본인 세션 로그 파일 만들기 (`로그/세션로그-{이름}-{날짜}.md`)
- 작업 끝: 커밋 + 푸시, 로그에 결정/막힌 점 정리
- 회의 있는 날: [[../템플릿/회의록-템플릿]] 복사해서 `회의록/{날짜}.md` 만들기

## 코드 규칙 핵심 (CLAUDE.md 발췌)

- 하드코딩 금지, 디자인 토큰 사용 (`text-text-strong`, `bg-button-primary`, `p-400` 등)
- 컴포넌트는 `cva + cn()` 패턴, `forwardRef` 금지 ([[../아키텍처/결정-기록/ADR-001-react-compiler]])
- 새 UI 컴포넌트 만들면 `src/components/ui/index.ts`에 export 추가
  - shadcn에 있는 컴포넌트는 최대한 활용하기
- 커밋 메시지: `[type]: 메시지` (feat/fix/refactor/chore 등), main 직접 커밋 금지
