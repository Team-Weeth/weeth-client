`isAdmin` 조건 분기가 5개 이상 누적되면 별도 컴포넌트로 분리. 중복 코드보다 유지보수성 우선.

- `CalendarMini` → `AdminCalendarMini` + `CalendarMini` (7개 분기)
- `CalendarGrid` → `AdminCalendarGrid` + `CalendarGrid` (6개 분기)
- `CalendarUpcomingPanel` → `AdminCalendarUpcomingPanel` + `CalendarUpcomingPanel` (5개 분기)

어드민 전용 컴포넌트는 `src/components/admin/schedule/`에 배치.

### CSS 변수 → JS 상수 동기화
`window.matchMedia()`는 CSS custom property(`var()`)를 지원하지 않으므로, JS 상수 파일(`constants/shared/breakpoints.ts`)을 만들어 `globals.css @theme`과 수동 동기화. 두 파일 중 하나를 수정할 때 함께 반영해야 함.
