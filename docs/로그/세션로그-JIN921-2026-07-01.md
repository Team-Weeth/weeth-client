## 논의된 것 — `watch` 구독 vs `useWatch`

store 동기화에 `watch((v) => setField(...))` 구독을 useEffect 안에서 사용. "useWatch가 낫지 않냐"는 질문에 대한 결론:

- **이 용도(사이드이펙트 store 동기화)에는 `watch` 구독이 맞다.** `watch` 구독은 컴포넌트 리렌더를 유발하지 않음. `useWatch`는 값을 렌더에 쓰기 위한 것이라 매 키 입력마다 Step 전체가 리렌더됨 → 성능 손해
- 기준점 `CreateClubForm`도 draft 동기화는 `watch` 구독, 렌더에 쓰는 값(`contactType` 등)은 `useWatch`로 나눠 씀
- React Compiler 경고 `react-hooks/incompatible-library`(watch 반환 함수 메모이즈 불가)는 **정보성 경고**일 뿐, cleanup에서 unsubscribe하므로 실제 버그 위험 없음. `CreateClubForm`도 이 경고를 그대로 안고 감
