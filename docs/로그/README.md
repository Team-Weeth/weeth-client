# 세션 로그

각자의 Claude Code / Claude Desktop 작업 기록. **매일 아침 팀원들의 로그를 훑는 것**만으로 어제 무슨 일이 있었는지 파악된다.

## 파일명 규칙

```
세션로그-{이름}-{YYYY-MM-DD}.md
```

예: `세션로그-민수-2026-06-01.md`

## 작성 규칙

- 하루에 한 파일. 작업이 길어지면 같은 파일에 이어 쓴다.
- Claude와의 대화 전체를 복사하지 않는다. **결정·이유·막힌 지점**만 정리.
- 다른 팀원이 알아야 할 변화는 "공유할 것" 섹션에 명시.
- 양식: [[../템플릿/세션로그-템플릿]]

## 왜 쓰나

- 비동기 협업의 기본 자료. 슬랙은 흘러가지만, 여기 남은 건 검색된다.
- 본인이 "지난주에 이거 왜 이렇게 했지?" 회상할 때 가장 빠른 자료.
- 옵시디언 백링크가 "민수가 ADR-001을 언급한 모든 로그"를 자동으로 모아준다.
