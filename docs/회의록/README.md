# 회의록

## 파일명 규칙

```
YYYY-MM-DD.md              ← 정기/주간 회의
YYYY-MM-DD-{주제}.md       ← 특정 주제 회의 (예: 2026-06-08-출석개선.md)
```

## 작성 규칙

- 회의 *전*에 안건만 적어두고 시작 (`템플릿/회의록-템플릿` 복사)
- 회의 *중*에는 결정과 액션 아이템만 빠르게 기록
- 회의 *후*에 정리/링크 보강
- 결정 사항이 큰 결정이면 → 별도 [[../아키텍처/결정-기록/README|ADR]]로 승격하고 회의록에서 링크

## 액션 아이템

- `- [ ] @담당자 — 무엇 — 언제까지` 형식 고정
- 다음 회의에서 첫 번째로 점검

## 옵시디언 활용

- 데일리노트 플러그인을 켜면 오늘 날짜 회의록을 단축키 하나로 생성 가능
- `@이름`을 일관되게 쓰면 그 사람이 언급된 모든 회의를 백링크로 추적 가능
