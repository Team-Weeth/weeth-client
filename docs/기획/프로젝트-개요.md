# Weeth — 프로젝트 개요

## 한줄 요약
> 동아리 운영과 커뮤니티를 한 곳에서 처리하는 웹 서비스.

## 현재 목표 (이번 분기)
- (채워넣기) 예: 출석 시스템 안정화, 어드민 대시보드 출시

## 핵심 기능
- 인증 (로그인/회원가입) — 담당: @미정
- 게시판 — 담당: @미정
- 출석 관리 — 담당: @미정
- 마이페이지 — 담당: @미정
- 어드민 — 담당: @미정

→ 자세한 담당 분배: [[기획/기능별-담당]]

## 기술 스택
- React 19 + Next.js 16 (App Router) + TypeScript
- Tailwind v4, cva, shadcn/ui, Radix
- TanStack Query + Zustand
- tiptap (리치 에디터)
- 인증: 쿠키 기반 (accessToken / refreshToken)
- 패키지 매니저: **pnpm 전용**

> 기술 결정의 *이유*는 [[아키텍처/결정-기록/README|ADR]]에 기록한다.
