# 도메인 용어집

코드와 회의에서 같은 단어를 같은 뜻으로 쓰기 위한 사전. 실제 `src/types/`와 `src/lib/apis/`를 기준으로 정리.

## 사용자 / 권한

- **User** — 가입한 사용자 단위. `userId`(number)로 식별.
- **Member (회원)** — _특정 클럽에 속한 사용자_. `clubMemberId`로 식별 (User ≠ Member, User는 여러 클럽에서 각각 다른 Member가 된다).
- **Role** — 전역 권한. `'LEAD' | 'ADMIN' | 'USER'` (3단계)
  - `LEAD` — 동아리장
  - `ADMIN` — 운영진
  - `USER` — 일반 회원
- **MemberRole** — 마이페이지에서 쓰는 축약 권한. `'USER' | 'ADMIN'`
- **MemberStatus** — `'ACTIVE' | 'INACTIVE' | 'BANNED'` (활동/비활동/제재)

> 코드에 `Role`과 `MemberRole`이 따로 존재. 상황에 따라 골라 쓴다. 새 화면 만들 때 어느 쪽을 받을지 먼저 결정.

## 클럽 / 기수

- **Club (클럽)** — 동아리. `id`(string)로 식별. 라우트의 `[clubId]` 동적 세그먼트가 곧 이 값.
  - 필드: `name`, `code`(가입 코드), `schoolName`, `description`, `contactEmail`, `contactPhoneNumber`, `primaryContact`(`'PHONE' | 'EMAIL'`), 이미지 URL들
- **Cardinal (기수)** — 클럽 내부의 세대 단위. 다른 프로젝트에서 흔히 "generation"으로 부르지만 **우리 코드는 `cardinal`로 통일**.
  - 필드: `id`, `cardinalNumber`(1, 2, 3…), `status`(`'IN_PROGRESS' | 'COMPLETED'`)
  - `Member.cardinals: number[]` — 해당 회원이 속한 기수 번호들

> "기수" / "세대" / "generation"은 회의에서 쓰지 말고 **Cardinal** 또는 **N기**로 통일.

## 출석

- **Session (세션)** — 출석 대상이 되는 모임 1회. `sessionId`로 식별.
- **AttendanceStatus** — `'ATTEND' | 'ABSENT' | 'PENDING'` (출석/결석/대기)
- **AttendanceCode** — 세션마다 발급되는 숫자 코드. 회원이 입력해 출석 처리.
- **QR Code** — `{ sessionId, code, expiredAt }`. 운영진이 띄우면 회원이 스캔.
- **AttendanceRecord** — 회원의 개별 출석 기록 1건.
- **AttendanceSummary** — `attendanceCount / total / absenceCount + 기록 배열`.

## 게시판

- **Board (게시판)** — 게시판 종류. `BoardType: 'ALL' | 'NOTICE' | 'GENERAL'`
  - `ALL` — 전체 보기 가상 게시판
  - `NOTICE` — 공지
  - `GENERAL` — 일반
- **BoardConfig** — `{ canWrite, canComment }`. 권한별로 쓰기/댓글 가능 여부.
- **Post (게시글)** — `tiptap`으로 작성된 콘텐츠. `id`, `boardId`, `title`, `content`(HTML), `author`, `files`, `like`, `commentCount`.
- **PostAuthor** — `{ id, name, profileImageUrl, role }`
- **Comment / PostComment** — 댓글. `children`으로 대댓글 트리 구성. `isDeleted` 플래그.
- **MappedComment** — UI 표시용으로 변환된 댓글 (`mapComment` 결과).
- **PostLike** — `{ isLiked, likeCount }`. 좋아요 API는 `boardId`까지 함께 응답.

### 파일 업로드 의미 규칙 (중요)

`UpdatePostBody.files` / `UpdateCommentBody.files`는 세 가지 의미를 갖는다:

- `null` — 변경 없음 (기존 파일 유지)
- `[]` — 전체 삭제
- 배열 — 교체

→ 새 API 만들 때 같은 규칙을 따른다. 다른 규칙이 필요하면 ADR로 남길 것.

## 인증

- **accessToken / refreshToken** — 쿠키로 보관. 클라이언트 JS는 직접 읽지 않는다.
- **소셜 로그인** — Apple, Kakao 지원 (라우트: `app/(public)/apple/`, `app/(public)/kakao/`).

## 라우트 / 레이아웃 구조

- `(private)/[clubId]/(main)/` — 일반 사용자 메인 (홈, 게시판, 출석, 마이페이지)
- `(private)/[clubId]/admin/` — 어드민 (멤버, 게시판, 일정, 클럽 정보, 출석)
- `(public)/(auth)/` — 로그인/회원가입
- `(public)/landing/` — 랜딩
- `(public)/club/` — 클럽 가입 등 클럽 공개 페이지

`[clubId]`가 동적 세그먼트라 **사용자는 클럽을 바꿔가며 사용**할 수 있다. URL이 곧 컨텍스트.

## 그 외

- **Inquiry (문의)** — 사용자 → 운영팀 문의.
- **Popup (팝업)** — 홈에 노출되는 공지/이벤트 팝업.
- **University** — 학교 정보. 가입 시 학교 선택용.
