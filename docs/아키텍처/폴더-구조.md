# 폴더 구조 (요약)

> 정식 규칙은 루트의 `.claude/rules/architecture.md`. 이 문서는 옵시디언에서 바로 보는 빠른 지도.

## `src/` 한눈에

```
src/
  app/                          # Next.js App Router
    (private)/
      (auth)/                   # 인증 필요한 부속 페이지
      [clubId]/                 # 클럽 컨텍스트 (동적 세그먼트)
        (main)/                 # 일반 사용자: home, board, attendance, mypage, terms, privacy
        admin/                  # 어드민: member, board, schedule, club-info, attendance
    (public)/
      (auth)/                   # 로그인/회원가입
      apple/, kakao/            # 소셜 로그인 콜백
      club/                     # 클럽 공개 페이지
      landing/                  # 랜딩

  components/
    ui/                         # 공용 UI
    layout/                     # Header, Footer 등
    admin/, auth/, board/,      # 도메인별 컴포넌트
    home/, mypage/

  lib/
    actions/                    # Server Actions ('use server')
    apis/                       # API 호출 (instance.ts + 도메인별)
    schemas/                    # Zod 등 검증 스키마
    cn.ts

  stores/                       # Zustand (use{Name}Store.ts)
  hooks/                        # 커스텀 훅
  types/                        # 타입 정의
  constants/
  assets/icons/                 # SVG
  providers/
```

## 배럴(`index.ts`) 사용 지양

런타임 코드에서는 `index.ts` 배럴 import보다 실제 파일 경로 direct import를 우선한다.

배럴 import는 Next.js/Turbopack이 더 넓은 모듈 그래프를 탐색하게 만들고, 사용하지 않는 Client Component, 아이콘, 훅, 무거운 라이브러리가 route client graph에 포함될 수 있다.

지양 대상:

- `@/components/ui`
- `@/components/{feature}`
- `@/hooks`
- `@/assets/icons`
- `@/assets/icons/{category}`
- Client Component에서 `@/lib/apis`

```ts
// Good
import { Button } from '@/components/ui/Button';
import AdminUserIcon from '@/assets/icons/admin/ic_admin_user.svg';

// Bad
import { Button } from '@/components/ui';
import { AdminUserIcon } from '@/assets/icons/admin';
```

타입만 모아두는 배럴은 `import type`으로만 사용하는 경우 허용한다.

## 라우트 그룹 명명

- `(private)` — 인증 필요
- `(public)` — 비로그인 접근 가능
- `(main)` — 일반 사용자 레이아웃
- `(auth)` — 로그인/가입 레이아웃
- `(landing)` — 랜딩 레이아웃

## 어드민 컨텍스트

`(private)/[clubId]/admin/layout.tsx`의 루트 요소에 `data-admin` 속성 필수. 이 속성이 있어야 어드민 전용 타이포그래피 스케일이 적용된다.

```tsx
<div data-admin>{children}</div>
```
